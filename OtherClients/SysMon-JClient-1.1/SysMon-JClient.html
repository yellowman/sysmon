About:

SysMon-JClient is a java based interface to the Sysmon (System Monitoring Daemon) written by Jared Mauch

Feb 2, 1997: Version 1.1 Released!

The new version has the following enhancements:

  • You can now cancel a pending refresh by clicking on the "Cancel Refresh" button.
  • The applet can be spawned into a separate window. This allows you to resize the applet to your liking.

How to run as a Java Application:

Running JClient as an application has one main advanatge: you can select which host you want to connect to. To run JClient as an application, do the following:

  • Download the application file. It is available as a "ZIP" or a "TAR.GZ"
  • Unzip or untar the file into a directory.
  • For UNIX users, run the "JClient.sh" shell script, or for Win32 users, run "JClient.bat". This script sets up the java CLASSPATH and runs the application. If you want to change the default host and port that JClient connects to, edit the shell script or batch file.
