You can extract various information via the following method from sysmon:

telnet <sysmon-host> 1345
AUTH <configured-auth-key>
MODE xml
SHOWOBJ <Object-Name>

other notes:

Outage history is written to a file in the following format:

<SysmonOutageHistory>
  <Object>object-name</Object>
  <ObjectType>object-type</Object>
</SysmonOutageHistory>
