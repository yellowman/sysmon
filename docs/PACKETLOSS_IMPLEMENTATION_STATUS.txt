? Phase 1: Data Structures (config.h)

  - SYSM_TYPE_PKTLOSS (22) - New monitoring type

Configuration Constants:
`c
define PKTLOSS_HISTORY_SIZE     1440  // 24 hours @ 1 minute intervals
define PKTLOSS_DEFAULT_HISTORY  24    // Default hours to keep
define PKTLOSS_MAX_HISTORY      168   // Max 7 days (1 week)
`

Data Structures:
`c
struct pktloss_sample {
    time_t timestamp;
    unsigned int sent;
    unsigned int received;
    unsigned int lost;
};

struct pktloss_data {
    struct pktloss_sample history[PKTLOSS_HISTORY_SIZE];
    unsigned int history_head;
    unsigned int history_count;
    unsigned long long total_sent;      // 64-bit for overflow protection
    unsigned long long total_received;
    unsigned long long total_lost;
    struct pingdata *ping;
};
`

Host Configuration (struct hostinfo):
`c
unsigned int pktloss_tolerance;      // Max lost packets before alert
unsigned int pktloss_history_hours;  // Hours of history to keep
time_t pktloss_last_check;           // Last evaluation time
`

? Phase 2: Core Implementation (icmp.c)

Functions Implemented:

1. pktloss_add_sample() - Add sample to history
  - Circular buffer management
  - Overflow protection on totals
  - Automatic oldest sample overwrite

2. start_test_pktloss() - Initialize monitoring
  - Allocates pktloss_data structure
  - Allocates embedded pingdata
  - Sets up ICMP socket
  - DNS lookup
  - Sends initial ping
  - Full NULL checking and error handling

3. service_test_pktloss() - Periodic monitoring
  - Sends ICMP packets
  - Tracks responses
  - Records history samples
  - Checks tolerance threshold
  - Returns appropriate status

4. stop_test_pktloss() - Cleanup
  - Frees all allocated memory
  - Proper cleanup order

Security Features:
  - ? All MALLOC calls have NULL checks
  - ? Overflow protection on totals (64-bit)
  - ? Bounds checking on circular buffer
  - ? No hardcoded sizes (uses macros)
  - ? memset after allocation
  - ? Proper cleanup on errors
